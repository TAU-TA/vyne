# Hello, world

**Since:** v0.0.1-alpha (documentation target; release tag to confirm)

## First program

```vyne
out("Hello, world!");
```

`out` writes a value to standard output; the C runtime adds a newline. Statements end with `;`.

**Run it:** use your project’s Vyne executable to compile this file, then run the resulting program. The executable name and switches are not present in the supplied files; this documentation deliberately does not guess them.
