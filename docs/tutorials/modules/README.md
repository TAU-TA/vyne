# Standard module index

**Since:** v0.0.1-alpha (documentation target; release tag to confirm)

**Verified against supplied headers and native maps:** [vcore](vcore.md), [vmath](vmath.md), [vmem](vmem.md). A module header alone does not prove a symbol is exported to source; these pages use the attached dispatch tables.

**Planned, not documented as installed:** `vfs`, `vurage`, `vcv`, `vaudio`, `vnet`, `vserv`, `vml`, `vglib`. Their implementations and complete dispatch tables were not supplied. Request them before publishing function indexes or examples.
