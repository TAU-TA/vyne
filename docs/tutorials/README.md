# Vyne language documentation

**Since:** v0.0.1-alpha (documentation target; release tag to confirm)

Read [the tour](getting-started/tour.md) first, then use the [language reference](reference/README.md) for exact behavior. The [cookbook](cookbook/README.md) provides small tasks. The [module index](modules/README.md) distinguishes verified modules from planned coverage.

**Evidence and limitations.** These pages are based on the supplied lexer, parser, AST, codegen, runtime and module headers—not on a complete release checkout. The CLI entry point, complete external modules, test suite, and version metadata were not supplied. An example labeled **illustrative** needs a run through the full compiler before publication; no undocumented command is invented. See [verification](verification.md).

> **Caution:** Do not promote an example to “tested” without parsing, transpiling, compiling, and running it in the complete repository.
