Standard Library

VGLib

Hardware-accelerated 2D/3D graphics, built on Raylib. 8 modules, 65+ native bindings.

importvyne
module vglib;
Core — window & frame loop
10 functions
vglib.init(width, height, fps, title, flags) → Bool
Initialises the window and target frame rate.
vglib.running() → Bool
True while the window is open.
vglib.begin(), vglib.end() → Null
Begin and end a drawing frame. Draw calls must be between them.
vglib.clear(color) → Null
Clears the background. Use vglib.rgba(r, g, b, a) to build the color integer.
vglib.clear_gradient(top, bottom) → Null
Fills the screen with a vertical gradient.
vglib.close(), vglib.get_fps() → Null/Int64
Close the window; read the current FPS counter.
2D rendering — shapes, text, textures
12 functions
vglib.line(x1, y1, x2, y2, color), rect(x, y, w, h, color), circle(x, y, r, color) → Null
Basic shape drawing primitives.
vglib.text(text, x, y, size, color), text_ex(font, text, x, y, size, color) → Null
Draw text with the default or a loaded font.
vglib.load_font(path) → Font, measure_text(font, text, size) → [w, h]
Font loading and measurement.
vglib.load_texture(path) → Texture, draw_texture(tex, x, y, w, h, color) → Null
Texture loading and drawing. Supports PNG, JPG, BMP, TGA.
vglib.draw_phase_scope(...), draw_spectrum_analyzer(...), draw_scanlines(spacing, color) → Null
Animated retro visualisation helpers.
3D rendering — cameras, meshes, models
20 functions
vglib.camera(fovy) → Camera, begin3d(cam), end3d() → Null
Create a camera and wrap 3D draw calls.
vglib.line_3d(x1, y1, z1, x2, y2, z2, color), cube(x, y, z, size, rot, color), plane(x, y, z, w, h, color), grid(slices, spacing) → Null
Primitive 3D draw calls.
vglib.load_model(path) → Model, draw_model(model, x, y, z, scale, color) → Null
Load and draw OBJ / GLTF / IQM models.
vglib.update_camera(cam, mode), get_pos(cam), set_pos(cam, x, y, z), move_forward(cam, dist), move_right(cam, dist), rotate_view(cam, sens) → Null
Camera controls for free-look and orbital modes.
vglib.draw_instances(model, instances), draw_instances_ex(model, instances, cam, dist) → Null
Instanced rendering with optional distance culling. Each instance is [x, y, z, scale].
Shaders & post-processing
8 functions
vglib.load_shader(path[, vs_path]) → Shader
Loads GLSL shader source. One path = fragment only; two = vertex + fragment.
vglib.begin_shader(shader), end_shader() → Null
Wrap draws in a shader.
vglib.set_shader_value(shader, uniform, value) → Null
Set a shader uniform. Accepts Float64 or [Float64, Float64].
vglib.load_render_texture(w, h), begin_texture_mode(t), end_texture_mode(), draw_canvas_scaled(t) → RenderTexture/Null
Offscreen render targets for multi-pass effects.
Map, AI, & collision
7 functions
vglib.load_map(path) → Array
Parses a .dat map file into [x, y, z, size] block descriptors.
vglib.pathfind(start, target, map, grid_size) → [dx, dy, dz]
AI obstacle avoidance. Returns a normalised direction vector.
vglib.check_collision(pos, size, cube_pos, cube_size), check_collision_map(pos, size, map) → Bool
Box-vs-box collision tests.
vglib.export_obj(map, filename) → Bool
Exports a map as Wavefront OBJ for external editing.
vglib.get_ray_grid(cam, dist, grid), distance_3d(a, b) → [x, y, z]/Float64
Ray-grid snapping and Euclidean distance.
Input — keyboard & mouse
10 functions
vglib.key_down(key), key_pressed(key) → Bool
key_down is true while held; key_pressed is true on the frame it was pressed.
vglib.get_char(), get_key() → String/Int64
The last character or key code.
vglib.mouse_down(btn), mouse_pos(), mouse_delta(), mouse_wheel() → Bool/[x, y]/Float64
Mouse state queries.
vglib.disable_cursor(), enable_cursor() → Null
Lock / unlock the cursor for FPS-style control.

Constants

Key codes (vglib.KEY_A … vglib.KEY_DELETE), color names (vglib.COLOR_RED etc.), window flags (vglib.FULLSCREEN, vglib.VSYNC), camera modes (vglib.CAMERA_FREE …), and mouse buttons (vglib.MOUSE_LEFT …). All are read-only Int64 constants.
