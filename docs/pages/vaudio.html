Standard Library

VAudio

Professional-grade DSP toolkit: compressor, 7-band parametric EQ, FDN reverb, LUFS metering, BPM detection, and 3D spatial audio. 8 modules, 45+ bindings.

importvyne
module vaudio;
Core — device & sounds
13 functions
vaudio.init_audio() → Bool, close_audio() → Null
Initialise / close the audio device. Defaults to 48 kHz, 32-bit float, stereo.
vaudio.volume(level) → Bool
Master volume in [0.0, 1.0].
vaudio.load_sound(path) → SoundHandle
Load a WAV, MP3, FLAC, or OGG file into memory.
vaudio.play_sound(h), pause_sound(h), resume_sound(h), stop_sound(h) → Bool
Playback control. Supports overlapping instances.
vaudio.is_playing(h), is_paused(h) → Bool
Playback state queries.
vaudio.sound_volume(h, level), set_pitch(h, p), seek_sound(h, sec) → Bool
Per-sound volume, pitch (1.0 = normal), and seeking.
Streaming — music & large files
10 functions
vaudio.play_stream(path) → StreamHandle
Streams a file from disk with looping.
vaudio.update_stream(h) → Null
Call every frame while streaming.
vaudio.pause_stream(h), resume_stream(h), is_stream_playing(h), seek_stream(h, sec), get_stream_pos(h) → Bool/Float64
Stream playback control. get_stream_pos returns [0.0, 1.0].
vaudio.get_waveform(path[, bins]) → Array<Float64>
Extracts normalised waveform peaks for visualisation.
vaudio.attach_master_limiter(h) → Bool, set_dsp(drive, mode) → Null
True-peak limiter (-0.9 dBFS) and global saturation.
Compressor — dynamic range
5 functions

Attach the compressor chain to a sound or stream.
vaudio.set_compressor(thresh, ratio, attack_ms, release_ms, makeup_db[, enabled[, auto_makeup]]) → Bool
Studio-grade parameter set. Threshold in dBFS, ratio as N:1.
vaudio.get_gr(), get_rms(), get_env() → Float64
Real-time metering: gain reduction in dB, normalised RMS, and envelope.
Equalizer — 7-band parametric
5 functions
vaudio.attach_eq(h) → Bool
Attach the 7-band EQ. ISO frequencies: 60, 150, 400, 1000, 2500, 6000, 14000 Hz.
vaudio.set_eq(band, freq, gain_or_type, Q[, mode]) → Bool
Configure one band. Mode: 0=LPF, 1=HPF, 2=Peaking (default).

Weighted center frequencies of the low, mid, and high bands.

3 functions

Four-line feedback delay network. Decay and mix in [0, 1], predelay 0–100 ms, damping in [0, 1].
vaudio.get_analyzer_env() → Float64
Envelope follower output.
Analysis — LUFS, BPM, offline render
5 functions
vaudio.get_lufs() → Float64
ITU-R BS.1770 loudness measurement.
vaudio.attach_bpm(h) → Bool, get_bpm(h) → Float64
Low-pass beat tracking in the 50–200 BPM range.
vaudio.attach_analyzer(h) → Bool
Real-time envelope and spectrum tracking.

3D audio & saturation modes
1 function + 5 modes
vaudio.sound_3d(h, listener, source, max_dist[, max_vol]) → Float64
Positions a sound in 3D space and returns the attenuation-weighted volume.
Saturation modes for set_dsp(drive, mode)
0 Soft tube · 1 Hard clip · 2 Asymmetric · 3 Tape · 4 GameBoy (4-bit DAC + sample-rate reduction).
DSP chain order
When you attach multiple processors to the same sound or stream, they run in a fixed order: EQ → Compressor → Saturation → Reverb → Limiter. This matches typical mastering signal flow and cannot be changed at runtime.
