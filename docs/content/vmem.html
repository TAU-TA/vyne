4 functions
vmem.total_allocated() → Int64
Total bytes handed out by the arena since program start, minus any reclaims. Drops back when a region rewinds.
vmem.checkpoint() → Int64
Pushes an arena checkpoint and returns its handle. The region keyword uses this internally; you rarely need it directly.
vmem.rewind(handle :: Int64) → Null
Rewinds the arena to a previously captured checkpoint.
vmem.reset() → Null
Drops the entire arena. Only safe at top level when no live value refers to arena memory. Intended for tests.
reset() is destructive
vmem.reset() frees every arena block. Any VyneValue still pointing into the arena becomes a dangling reference. Do not call it in normal code.
