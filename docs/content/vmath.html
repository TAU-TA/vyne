vmath.random(lo, hi) → Int64
Uniform random integer in [lo, hi] inclusive. Uses PCG32 seeded from time().
vmath.random_float(lo, hi) → Float64
Uniform random float in [lo, hi). Shares the RNG state with random.
Random seeding
The generator is seeded once on first call with a mix of time() and the address of the state variable. Two processes started in the same second will produce decorrelated output, but two runs in the same process always produce different sequences.
