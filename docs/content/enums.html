Language Reference

Enums

Named Int64 constants. Auto-numbering with explicit overrides.

Syntax

enums.vyvyne
enum Direction { North, // 0 East, // 1 South = 10, // 10 (resets counter) West // 11 }; out(Direction.South); // → 10

Semantics

  • The backing type is always Int64.
  • Members are const — reassignment is a compile error.
  • An explicit = N resets the auto-increment counter from that point.
  • Enums are global. There is no namespacing beyond the enum name itself.

Using an enum

use-enum.vyvyne
heading :: Int64 = Direction.North; if (heading == Direction.North) { out("heading north"); };

Because enum members are plain Int64, you can store them in typed arrays, compare them with integers, and pass them anywhere an Int64 is expected.
