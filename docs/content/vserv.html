Standard Library

VServ

HTTP / WebSocket server with Express-style routing. Native C under the hood, no external dependencies.

importvyne
module vserv;
Core — create, route, listen
8 functions
vserv.create_server(port) → ServerHandle
Create an HTTP server bound to port.
vserv.server_get(srv, path, handler), server_post, server_put, server_delete → Bool
Register a route handler for a given method and path.
vserv.server_use(srv, middleware) → Bool
Register middleware that runs before every route.
vserv.server_listen(srv) → Bool
Starts the server. Blocks until stopped.
vserv.serve_file(path) → Response
Creates a response that serves a static file with the correct MIME type.
Request & response
6 functions
vserv.parse_request(raw) → Request
Parses raw HTTP bytes into a structured Request.
vserv.create_response() → Response
Creates an empty 200 response.
vserv.set_status(res, code), set_header(res, key, value) → Response
Set status code and headers. Both return the response for chaining.
vserv.send(res[, body]), send_json(res, data) → String
Serialise the full HTTP response. send_json sets Content-Type: application/json.
Express-style app & WebSocket
6 functions

vserv.app_get(app, path, handler), app_post(app, path, handler) → AppHandle

Status codes & MIME types

Read-only Int64 constants: vserv.OK, CREATED, ACCEPTED, NO_CONTENT, BAD_REQUEST, UNAUTHORIZED, FORBIDDEN, NOT_FOUND, METHOD_NOT_ALLOWED, SERVER_ERROR, and so on.

MIME type strings: vserv.MIME_HTML, MIME_JSON, MIME_CSS, MIME_JS, MIME_PNG, MIME_JPG, MIME_WASM, MIME_MP4, MIME_MP3, and so on.

Complete example

api.vyvyne
module vserv; module vcore; app :: vserv.AppHandle = vserv.create_app(); // Logger middleware fn logger(req, res, next) { vcore.out("[" + req.method + "] " + req.path); next(); }; vserv.app_use(app, logger); // GET /hello vserv.app_get(app, "/hello", fn(req, res) { vserv.send(res, "Hello, World!"); }); // POST /api/users vserv.app_post(app, "/api/users", fn(req, res) { vserv.send_json(res, { "created": true, "data": req.body }); }); vserv.app_listen(app, 3000); vcore.out("Server running on port 3000");
